How a support session works

1

Open Assist

The person receiving assistance opens the client and receives a temporary six-digit support code.

2

Share the code

Give the temporary code only to the person who will provide support.

3

Approve access

Desktop viewing and remote control begin only after the customer approves the requested display.

Support codes are temporary. Remote desktop capture does not begin automatically when a session connects. The customer remains in control of display approval and can end the session at any time.
