# ScottiBYTE Assist 2.0.2

ScottiBYTE Assist 2.0.2 is the current Windows and Ubuntu Linux client release.

## Highlights

- Added the interactive **Customer Terminal** for attended command-line support.
- Improved Windows application sharing, including minimized application windows.
- Improved cross-platform remote terminal behavior and presentation.
- Improved Linux terminal readability and shell startup behavior.
- Refined Windows remote-control interface behavior.
- Corrected the **Full Screen Remote Control** label on Windows.
- Improved support-code copy/check placement on Windows and Linux.
- Refreshed the Receive Support and Provide Support documentation images.

## Customer Terminal

An authorized provider can select **Open Customer Terminal** during an active
support session to obtain an interactive terminal on the customer computer.

The terminal is part of the attended support session. Closing the terminal or
ending the support session ends that terminal access; it does not provide
persistent unattended access.

## Windows

Windows 2.0.2 includes:

- interactive customer terminal support;
- improved application/window share-source discovery;
- minimized-window share-source support;
- remote-control interface refinements;
- corrected **Full Screen Remote Control** labeling;
- improved support-code copy/check placement.

## Ubuntu Linux

Ubuntu Linux 2.0.2 includes:

- interactive customer terminal support;
- improved terminal shell initialization;
- larger default remote-terminal text;
- support-code copy/check placement matching Windows;
- continued X11 and Wayland remote-assistance support.

## Server

The current ScottiBYTE Assist server release remains **1.3.2**.

Docker images:

```text
scottibyte/scottibyte-assist-server:1.3.2
scottibyte/scottibyte-assist-server:latest
```
