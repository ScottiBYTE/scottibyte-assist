# ScottiBYTE Assist 3.0.0

## Versions

- Portal and server: 2.0.0
- Windows client: 3.0.0
- Linux client: 3.0.0

## Highlights

- Customers can send support requests from the client.
- Authorized providers can review and accept incoming requests.
- Server-side arbitration allows one provider to claim a requested session.
- On Windows, dragging the main window or a paired dialog moves the other window with it.
- The Linux client supports Ubuntu 24.04 LTS and 26.04 LTS.

Screenshots of the client and portal are in [the 3.0.0 screenshot guide](screenshots-3.0.0.md).
